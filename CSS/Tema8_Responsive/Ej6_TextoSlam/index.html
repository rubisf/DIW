Adaptación perfecta sin Media Queries

Este ejercicio utiliza la función clamp() de CSS para crear textos que escalan suavemente con el tamaño del viewport. A diferencia de usar solo vw, clamp nos permite definir un tamaño mínimo y máximo de seguridad.

Usando font-size: clamp(min, val_vw, max);
