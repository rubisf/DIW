Ejercicio de Display

Este es un párrafo completamente visible. Se renderiza con normalidad en el flujo del documento.

Este es el párrafo oculto. Si puedes leer esto sin usar DevTools, significa que has conseguido quitar el display: none con éxito. ¡Buen trabajo!

Inspecciona la página:

  1. Click derecho en cualquier parte y "Inspeccionar" (o F12).
  2. Busca la etiqueta <p class="parrafo-oculto"> en la pestaña Elements/Elementos.
  3. Desmarca la casilla display: none; en la pestaña de Estilos de las DevTools para revelar el párrafo secreto.
