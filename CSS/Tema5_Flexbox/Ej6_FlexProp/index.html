Ejercicio 6: Distribución con Flex-Grow

La propiedad flex (shorthand de flex-grow, flex-shrink y flex-basis) determina cómo el espacio sobrante se reparte entre los hijos.

Caja 1 flex: 1
Caja 2 (Doble) flex: 2
Caja 3 flex: 1

Observaciones:

  • El contenedor se divide en un total de 4 partes (1 + 2 + 1 = 4).
  • La Caja 2 ocupa 2/4 (el 50%) del espacio disponible.
  • Las Cajas 1 y 3 ocupan 1/4 (25% cada una) del espacio disponible.
  • Esto permite crear layouts proporcionales de forma muy sencilla sin usar porcentajes fijos.
