Reflexión sobre Reutilización:

Aunque aquí hemos copiado y pegado las clases bg-green-500 text-white p-3 rounded hover:bg-green-600, en proyectos reales de Tailwind esto se gestiona mediante componentes (en React/Vue) o mediante la directiva @apply en CSS para evitar la repetición manual si el proyecto crece.
