Ejercicio 3: Elección de Framework

¿Qué herramienta elegirías para un diseño 100% único?

"Imagina que quieres crear una web con colores personalizados, diseño propio y sin que se parezca a otras webs..."

Bootstrap
Tailwind CSS

💡 Por qué Tailwind CSS:

  • 1. Sin componentes pre-diseñados: A diferencia de Bootstrap, que impone botones y cards con estilos fijos, Tailwind te da "utilidades" (piezas de LEGO) para construirlo todo desde cero.
  • 2. Libertad Total: Permite implementar cualquier sistema de diseño (colores, sombras, espaciados) directamente en el HTML sin sobreescribir CSS complejo.
  • 3. Identidad Única: Evita el "efecto Bootstrap" donde miles de webs se ven iguales. Con Tailwind, el límite es tu imaginación.
