Manual de Instalación de VS Code

Requisitos

  • Ordenador con Windows, Mac o Linux
  • Conexión a internet
  • 200MB de espacio libre

Pasos de Instalación

  1. Descargar el instalador.
  2. Ejecutar el archivo descargado.
  3. Aceptar los términos y condiciones.
  4. Hacer clic en Instalar y esperar a que finalice.

Términos Técnicos

IDE
Entorno de Desarrollo Integrado.
Extensión
Paquete de software que añade nuevas capacidades al editor base.
