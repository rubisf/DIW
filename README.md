# Desarrollo de Interfaces Web (DIW)

Bienvenido/a al repositorio centralizado para el módulo de **Desarrollo de Interfaces Web**.

Este proyecto aloja un conjunto completo de recursos, materiales teóricos y, especialmente, ejercicios prácticos que cubren todo el espectro del desarrollo frontend moderno.

## 🗂️ Estructura del Repositorio

Los ejercicios y materiales están divididos temáticamente en los siguientes directorios:

- **`HTML/`**: Prácticas enfocadas en marcado semántico, estructuras de texto, integración de enlaces e imágenes, creación de formularios y optimización SEO en el `<head>`.
- **`CSS/`**: Ejercicios de diseño visual que van desde selectores básicos y modelo de caja, hasta arquitecturas de layout modernas usando **Flexbox** y **CSS Grid**.
- **`Tailwind/`**: Prácticas dedicadas al desarrollo rápido de interfaces utilizando el popular framework de utilidades CSS, abarcando desde componentes dinámicos hasta layouts complejos.
- **`Bootstrap/`**: Diseños y estructuras responsive implementadas con el framework de componentes Bootstrap.
- **`SASS y LESS/`**: Introducción y ejercicios con preprocesadores CSS para organizar y escalar las hojas de estilo.
- **`TeoriaInterfaces/`**: Material teórico complementario de la asignatura.

## 🚀 Dashboard Interactivo

En la raíz del proyecto encontrarás el archivo **`index.html`**. Éste funciona como un **Panel de Control** (Dashboard) centralizado desde el cual puedes navegar a todos los ejercicios de manera intuitiva y filtrarlos por tecnología.

### ¿Cómo funciona el Dashboard?

El repositorio contiene varios scripts en Python (`extract_*.py`) que analizan los documentos del curso para extraer el contenido de los ejercicios y generar archivos de datos en formato JSON (`ejercicios_*.json`). El archivo `index.html` lee esos JSON y construye la interfaz dinámicamente, asegurando que el panel esté siempre sincronizado con los ejercicios disponibles.

## 🔧 Uso y Visualización

1. Clona el repositorio en tu máquina local:
   ```bash
   git clone https://github.com/rubisf/DIW.git
   ```
2. Abre el archivo `index.html` en tu navegador web de preferencia.
3. Navega por las diferentes tarjetas y categorías para acceder a la solución de cada práctica y visualizar el código fuente de las plantillas.

## 📌 Enfoque Atemporal

Las plantillas, el contenido semántico y los ejemplos de código (como los metadatos SEO y los *footers*) han sido diseñados y redactados bajo un **enfoque atemporal**. Se han omitido referencias a años o fechas específicas de creación/actualización para garantizar que todos los ejemplos y el sitio se mantengan vigentes a largo plazo, basándose siempre en estándares y tecnologías actuales.
